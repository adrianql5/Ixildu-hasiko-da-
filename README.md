# Ixildu-hasiko-da!

Proyecto de Bases de Datos II centrado en el diseño y la implementación de un sistema de gestión para un cine.

## Descripción

El repositorio recoge el trabajo realizado para modelar, construir y documentar una base de datos orientada a la gestión de un cine. El sistema contempla elementos habituales de este dominio, como películas, salas, sesiones, usuarios, reservas y venta de entradas.

Además de los scripts SQL, el proyecto incluye material de diseño y una implementación de la aplicación.

## Estructura del proyecto

- `Diseño/`: documentación y scripts de base de datos.
- `Implementacion/`: aplicación desarrollada sobre la base de datos del proyecto.

## Contenido

- Modelo entidad-relación.
- Modelo relacional.
- Diccionario de datos.
- Definición de transacciones.
- Diseño de interfaces.
- Scripts SQL de creación, carga y eliminación.

## Scripts principales

- `scriptTablas.sql`: crea la estructura de la base de datos.
- `scriptInserts.sql`: inserta los datos iniciales.
- `scriptEliminar.sql`: elimina la base de datos.

## Ejecución

1. Ejecutar `Diseño/scriptTablas.sql` para crear la base de datos.
2. Ejecutar `Diseño/scriptInserts.sql` para cargar los datos iniciales.
3. Si se necesita reiniciar el entorno, ejecutar `Diseño/scriptEliminar.sql`.
